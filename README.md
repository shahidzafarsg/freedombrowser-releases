# FreedomBrowser downloads

A private web browser that keeps your browsing data encrypted, by [freedomsoft.uk](https://freedomsoft.uk).

This repository holds the official FreedomBrowser installers only. Download the latest version from
the [Releases page](https://github.com/shahidzafarsg/freedombrowser-releases/releases/latest).

To report a problem or ask a question, open an [issue](https://github.com/shahidzafarsg/freedombrowser-releases/issues).
